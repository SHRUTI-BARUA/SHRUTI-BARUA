## 📌 Featured Projects

### 🔥 [Forest Fire Prediction and Mapping System](https://github.com/SHRUTI-BARUA/FOREST-FIRE-PREDICTION)
`Python` `Scikit-learn` `Pandas` `NumPy` `Machine Learning`
End-to-end ML pipeline predicting wildfire risk from weather and vegetation data.
- Trained a Random Forest model achieving **0.79 ROC-AUC** with **77% high-risk recall**
- Simulated fire spread using cellular automata on model-predicted risk zones
- Integrated Twilio SMS alerts to automatically notify users on high-risk detection

### 💬 [SeekGPT](https://github.com/SHRUTI-BARUA)
`React` `Node.js` `Express.js` `MongoDB` `REST API`
Full-stack MERN application for real-time AI responses with chat history and streaming.
- Built RESTful APIs in Express.js with CRUD operations and Mongoose schema design
- Implemented state management via React Context API
- Markdown and syntax-highlighted code rendering for chat responses

### 🧠 [MiniGrad](https://github.com/SHRUTI-BARUA)
`Python`
An autograd engine built from scratch that computes derivatives via the chain rule.
- Supports core math operations (+, ×, tanh, exp)
- Trained a small neural network on top of it using gradient descent
- Verified gradients manually and cross-checked results against PyTorch

### ✈️ [Drone Object Detection](https://github.com/SHRUTI-BARUA/DRONE_OBJECT_DETECTION)
`Python` `YOLO` `Computer Vision`
Real-time object tracking and detection system with YOLO integration — the foundation of the aircraft detection work extended during my DRDO traineeship.
